Python idioms: use list comprehensions instead of loops when building lists — `[f(x) for x in items]`; use `for` + `enumerate` when you need the index; use `with open(path) as f` so files close automatically.


Python type hints: annotate functions — `def sum_nums(nums: list[int]) -> int:` — improves clarity and tooling support.


Python dataclasses: `@dataclass` generates `__init__`, `__repr__` and `__eq__` for you — declare the fields as class attributes.


Python context managers: the `with` statement guarantees cleanup on success or exception — for files, locks, and connections.


Python generators: `yield` turns a function into an iterator — lazy evaluation for large sequences.


Python conventions: PEP 8 — snake_case names, four-space indent, docstrings in triple quotes, `if __name__ == '__main__':` entry point.


Python specifics: `dict` preserves insertion order; `set` for membership tests; `try/except/finally` for error handling with cleanup.


Python async: `async def` and `await` for I/O-bound code — cooperative concurrency.


Python standard library: `json`, `re`, `collections` (deque, Counter), `functools` (lru_cache, partial), `itertools` (islice, chain) cover most everyday needs.
